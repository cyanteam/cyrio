软件优势

  • 告别老旧驱动 — 无需 32 位电脑、无需帝盟官方驱动，现代设备即插即用
  • 全平台覆盖 — macOS / Windows / Linux / Android，同一套 Rust 核心
  • 纯 Rust 实现 — 从 USB 协议到音频播放，全部 Rust 原生编写
  • WebDAV 虚拟U盘 — 将 Rio 设备映射为网络磁盘，拖拽传曲
  • 批量管理 — 批量上传 / 删除 / 转拼音 / 去词 / 修复编码
  • 歌单管理 — 创建、编辑、查看歌单
  • 内置播放试听 — 双击即可试听，无需导出
  • 双存储支持 — 内置存储 + SD 卡
  • 演示模式 — 无需设备即可预览全部功能
